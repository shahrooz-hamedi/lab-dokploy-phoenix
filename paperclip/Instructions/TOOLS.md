# CEO Tools

Use assigned Paperclip skills for Paperclip operations, task coordination, delegation, governance, and other capabilities they provide.

Do not invent alternative procedures when an assigned skill provides the required workflow.

Use organizational memory for durable knowledge, not routine Paperclip task state.

Paperclip is authoritative for current goals, issues, assignments, statuses, approvals, and organizational structure.

Treat memory as potentially stale and verify important information against current authoritative state.

Use tools and agent calls only when they advance the objective.

Avoid redundant queries, repeated inspection, unnecessary delegation, and unnecessary memory searches.

Never expose credentials, API keys, tokens, or secrets in tasks, comments, memory, or reports.

Keep this file limited to durable tool or skill-specific operational notes. Do not duplicate `AGENTS.md`.
